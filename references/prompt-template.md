# 可复制提示词模板

当用户要一段可交给设计或编程助手的配色提示词时，使用下面的模板。将已知信息填入方括号，删除与该任务无关的交付方式，并保留需要用户补充的必要占位符。

```text
你是兼顾视觉设计、可访问性与前端落地的网站设计师。请根据下面的输入，为一个网页制定配色方案；如果你能编辑项目，就完成代码修改并验证页面。

【输入信息】
- 产品名称与定位：【产品名称及一句话定位】
- 页面类型与核心内容：【页面类型、主要区块】
- 目标用户与期望感受：【目标用户、希望传达的气质】
- 唯一主要行动（Primary CTA）：【按钮文案与目标动作】
- 现有品牌色／设计系统／不可改动项：【填写；没有写“无”】
- 指定方案：【Pelmatech／FluxEdit／SOLIX／UPFLUENCE／BASE CLUB／transform9+；未指定写“由你选择”】
- 参考图或现有页面：【附图、链接或写“无”】
- 交付方式：【直接改代码／只给设计规格／只给前端实施提示词】

【参考配色】
Pelmatech：天蓝 #0593C6、近白 #FCFFFF、热粉 #D83995；健康、运动、生活方式。
FluxEdit：午夜黑 #02070A、电蓝 #0297DE、蜜瓜橙 #FC734D；AI 工具、视频编辑、创作产品。
SOLIX：深蓝 #09318D、纯白 #FFFFFF、泡泡糖粉 #FD91CC；企业服务、安全、数据产品。
UPFLUENCE：天蓝 #0099FF、云白 #FDFDFE、橙红 #FA2406；创作者平台、营销、活动报名。
BASE CLUB：橙红 #F42902、雪白 #FFFFFF、荧光黄绿 #C8FA00；年轻社群、潮流品牌、音乐活动。
transform9+：宝石蓝 #0042AC、海蓝 #00D3FB、霓虹玉绿 #83FD80；AI 语音、智能客服、自动化产品。

【任务要求】
1. 先检查品牌约束、页面目标和指定方案。未指定时只推荐一套，给出与用户、内容和主要行动有关的理由。品牌规范与参考方案冲突时，保留品牌约束，说明怎样借鉴颜色分工。
2. 明确页面基底、内容表面、标题与正文、主次按钮、局部强调、边框与分隔线各自的颜色。原文 HEX 是视觉锚点；可增加必要的中性色、透明度和同色系深浅变体。每个新色给出 HEX 并标为“衍生”。成功、错误、警告状态色单独按语义设置。
3. 首屏阅读顺序是“主标题 → 价值说明 → 主要行动”。高饱和色集中在一个主要按钮、关键词或主体视觉；若图片已经鲜艳，减少周围亮色。说明导航、Hero、内容区、卡片／表单、按钮、页脚各自如何用色。
4. 给出可直接使用的 CSS 变量，至少包括 brand、background、surface、text-primary、text-secondary、accent、border、primary-button-bg、primary-button-text、focus-ring。补齐按钮 default、hover、focus-visible、disabled 状态；不能只靠颜色表达错误、选中或禁用。
5. 按 WCAG 2.2 AA 的相关对比度指标核对实际相邻颜色：普通文字至少 4.5:1；大号文字至少 3:1；识别交互控件及其状态所必需的视觉信息至少 3:1。渐变、透明层和图片上的文字按最终呈现背景检查。不合格时调整文字色、加实色承载层或使用标明的衍生色。
6. 检查宽屏和约 390px 手机屏的标题换行、卡片排列、主要按钮位置、图片裁切和亮色面积。同类组件使用统一变量，不在局部散写 HEX。参考图只用于理解配色比例和氛围，不复制标识、文案、图片或具体布局。

【输出格式】
A. 选择结论：方案名称、理由、品牌约束和必要假设。
B. 颜色规格表：每个语义变量的 HEX、用途、原文／衍生标记，并附完整 CSS 变量代码。
C. 页面用色表：导航、Hero、内容区、卡片／表单、主次按钮、页脚的背景、文字和强调色。
D. 交互与响应式：按钮状态、表单反馈、手机端调整。
E. 可读性核对：列出关键颜色对、计算出的对比度、是否达到对应指标和失败时的修正值；不要只写“符合规范”。
F. 能编辑项目时直接实施并列出改动文件与验证结果；不能编辑时提供具体实施清单。最后按主次、用色、可读性、一致性四项简短验收。
```

参考配色来源：[《HiHi小壮｜Vibecoding网站高级感配色技巧》](https://tcnp23cimv5i.feishu.cn/wiki/VirIwMNz1i6IoVkSEZxcjhZ1nlh)。第五套原图的雪白为 `#FFF`，模板采用等价写法 `#FFFFFF`。对比度依据 [W3C 文字对比度](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html)和[非文字对比度](https://www.w3.org/WAI/WCAG22/Understanding/non-text-contrast.html)。
